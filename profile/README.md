### 🔬 Core Engineering Initiatives

- **KORA**: Local-first AI inference runtime & autonomous edge intelligence engine.
- **PATH**: WebAssembly-powered interactive kinematics & virtual laboratory simulation ecosystem.
- **AMS**: Autonomous agricultural robotics & precision soil telemetry system.
- **AWMS**: Android Web Management Service — lightweight, offline device control via MCP.
- **DORAAA**: Infinite spatial vector whiteboard for systems architecture and engineering notes.
- **KEYMEM**: Private on-device AI keyboard IME with offline contextual recall.
